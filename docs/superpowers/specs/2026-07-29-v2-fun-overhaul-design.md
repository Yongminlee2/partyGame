# v2.0 "노잼 탈출" 재미 전면 개선 설계 (2026-07-29)

## 배경

실기기 테스트 피드백: "개노잼". 인기 파티게임 앱 조사 결과와 자가진단으로 원인 확정:

| 문제 | 근거 |
|---|---|
| 긴장감 없음 | 솔로 퀴즈에 제한시간 없음 — 문제집처럼 느껴짐 |
| 연출 빈약 | 정답 시 ⭕ 하나. 인기 앱들은 큰 자막·진동·사운드로 도배 |
| 템포 끊김 | 매 문제 "다음" 클릭 요구 |
| 상대감 없음 | AI가 진행 바 하나 — 캐릭터성 0 |
| 대화 유발 콘텐츠 부재 | 술자리 앱들의 본체는 벌칙·질문 콘텐츠 (게임은 구실) |

참조: Heads Up!(단순 룰+덱 다양성), 술판(80게임·벌칙 중심), 쭈루쭈루(짧은 템포).

## A. 연출 엔진 — `web/js/core/fx.js` (신규)

모든 게임이 공유하는 예능식 연출 도구:

- `fx.caption(text, kind)` — 화면 중앙 대형 자막 팝업. kind: 'ok'(노랑, 튀어오름) /
  'bad'(빨강 도장 쾅) / 'combo'(주황, 회전 진입). 0.9초 후 자동 소멸
- `fx.confetti()` — 전체 화면 canvas 오버레이에 색종이 40개 낙하 (1.5초)
- `fx.shake()` — body에 shake 클래스 0.4초 (CSS keyframes)
- `fx.flash(color)` — 전체 화면 색 번쩍 0.15초
- `fx.vibrate(pattern)` — navigator.vibrate 래퍼 (미지원 시 무시).
  정답 [30], 오답 [80], 폭발 [300,100,300], 콤보 [30,30,60]
- 사운드 추가(sound.js): `sfx.heartbeat(rate)` 카운트다운 비트,
  `sfx.combo(n)` 콤보 수만큼 음 상승, `sfx.grade()` 결과 등급 팡파레

## B. 퀴즈 루프 개편 (사자성어·연예인 공통 → quiz.js 확장)

- **라운드 제한시간 15초**: 상단 카운트다운 바, 5초 남으면 heartbeat 가속.
  시간초과 = 오답 처리 후 자동 진행
- **점수**: 정답 시 `100 + 남은초×10` (빨리 맞힐수록 고득점). 힌트 1개당 -30 유지
- **콤보**: 연속 정답 n연속이면 획득 점수 ×(1+0.2n) 및 "n연속!!" 자막 + 콤보음
- **자동 진행**: 정답/오답 판정 후 1.5초 결과 노출(성어 뜻·인물 사진) 후 자동 다음 라운드.
  "다음" 버튼 제거
- **결과 등급**: 총점 기준 S/A/B/C/D + 예능 코멘트 2줄
  (예: S "미쳤다;; 이걸 다 맞히네" / D "국어책부터 다시 펴자…"). 등급별 코멘트 3개 중 랜덤
- quiz.js 인터페이스 변경: `answer(text, remainSec)` → `{correct, score, combo}`,
  `result()` → `{score, correct, total, maxCombo, grade}`

## C. AI 캐릭터화 (rival.js 확장 + 대전 UI)

- 난이도별 페르소나: 1 느긋이 🐢 / 2 보통이 🦊 / 3 독종이 😈
- 대전 화면에 AI 얼굴+이름 상시 표시. 상태: 대기(😐) → 생각(🤔, 답 임박 시 😏)
- AI가 먼저 맞히면 말풍선 도발 대사 랜덤 (10종: "ㅋㅋ 내가 먼저~", "이것도 몰라?" 등)
- 최종 승리 시 AI 우는 리액션(😭 + "한 판 더 해!"), 패배 시 AI 으스대기
- rival.js에 `taunt()`, `loseLine()`, `winLine()` 추가 (대사 배열에서 랜덤)

## D. 폭탄 게임 리메이크

- 중앙에 큰 폭탄 💣 + CSS로 심지 불꽃(✨ 흔들림) 연출, 시간이 갈수록 폭탄이 커지고 빨라짐
- 틱 사운드 점점 가속 (fuse 남은 비율 기반 — 단, 총 시간은 여전히 비공개 랜덤이므로
  가속은 "경과 시간" 기준 연출로만)
- 폭발: fx.flash + fx.shake + vibrate[300,100,300] + 💥 대형 연출
- 단어 성공 입력 시에도 짧은 진동

## E. 신규 게임 3종

### 1. 밸런스 게임 ⚖️ (`games/balance.js`, `data/balance.json` 150문항)
- 카드에 A vs B 표시 → 다같이: 하나 골라 태그하면 다음 카드 (대화 유발용)
- 혼자: 내 선택 후 AI 4명의 선택과 한 줄 이유 공개 (문항마다 aiSays 배열 데이터)
- 스키마: `{a, b, cat, aiSays:[{pick:'a'|'b', line}...2개 이상]}`
- 카테고리: 음식/연애/일상/극한상황/돈

### 2. 진실게임 🎯 (`games/truth.js`, `data/truth.json` 100문항)
- "여기서 제일 ~할 것 같은 사람은?" 지목형 카드. 넘기기만 하는 단순 카드 덱
- 파티 전용 (지목·해명은 오프라인에서 알아서). 수위: 전체이용가 (음주·성적 소재 금지 —
  플레이스토어 등급 유지)

### 3. 숫자야구 ⚾ (`games/baseball.js`)
- 서로 다른 3자리 숫자 맞히기. 판정: 자리·숫자 일치 S, 숫자만 B, 없음 OUT
- 솔로: 내가 AI 숫자를 추리 (기록표 표시, 시도 횟수 적을수록 등급)
- 대전: AI도 내 숫자를 동시에 추리 — 서로 번갈아 턴, 먼저 3S가 승리.
  AI 추리는 후보 집합 소거법(정석 알고리즘) + 난이도별 실수 확률
- 판정 함수 `judge(guess, answer) -> {s, b}` 순수 함수 + 테스트

## F. 벌칙 확장

- 룰렛 프리셋 15 → 60개 (`data/penalties.json`으로 분리, 룰렛에서 로드)
- 룰렛에 "벌칙 뽑기" 버튼: 항목 입력 없이 벌칙 카드 한 장 랜덤 뽑기 모드

## 성공 기준

1. 솔로 퀴즈 한 판(10문제)이 제한시간 압박 속에 클릭 없이 흘러간다
2. 정답·오답·콤보·폭발마다 화면이 반응한다 (자막+소리+진동)
3. AI와 붙으면 상대가 "보인다" (얼굴·대사·리액션)
4. 게임 10종, 대화 유발 콘텐츠(밸런스150+진실100+벌칙60) 탑재
