# 예능게임 앱 설계 (2026-07-28)

## 목표

나PD식 예능에서 나오는 게임들을 모은 파티+솔로 게임 앱.
웹(GitHub Pages)과 안드로이드 앱(플레이스토어 출시)을 **하나의 코드**로 지원한다.

- 서버 없음, 계정 없음. 기록은 localStorage.
- 앱 이름: 미정 (작업명 "예능게임"). 후보: 모여라 게임판, 예능킹, 국민게임.
- 프로젝트 위치: `C:\workAndroid\PartyGame`

## 기술 구조

**웹 우선 + WebView 래퍼** 방식.

```
PartyGame\
├── web\                  ← 게임 본체. 순수 HTML/JS/CSS, 빌드 도구 없음
│   ├── index.html        ← 홈(게임 선택 그리드)
│   ├── css\
│   ├── js\
│   │   ├── core\         ← 공용: 라우팅, 사운드, 저장, 유틸
│   │   ├── ai\           ← AI 봇 로직 (게임별)
│   │   └── games\        ← 게임별 화면·로직 (1게임 1파일)
│   └── data\             ← JSON 데이터 (직접 제작, 저작권 클린)
├── app\                  ← Android Kotlin WebView 래퍼
│   └── (gradle 태스크가 web\ 을 assets로 복사 → 오프라인 동작)
├── docs\superpowers\specs\
└── .github\workflows\    ← GitHub Pages 자동 배포 (web\ 폴더)
```

- 웹 배포: main 푸시 → GitHub Actions → Pages. 수정 즉시 반영.
- 앱: 같은 웹 번들을 assets에 내장. 플레이스토어의 "단순 웹뷰 래퍼" 거부 정책은
  콘텐츠 내장 오프라인 게임이므로 해당 없음.
- 화면: 모바일 세로 기준. 데스크톱 브라우저에서는 중앙 모바일 폭 카드 레이아웃.
- 센서: "몸으로 말해요" 기울기는 DeviceOrientation API. 미지원 환경은 화면 터치 대체.

## 게임 라인업 (v1.0)

| # | 게임 | 솔로 | 파티 | AI 역할 |
|---|------|------|------|---------|
| 1 | 연예인 퀴즈 (초성·사진) | O | O | 대전 상대 (정답 속도 경쟁) |
| 2 | 사자성어 뒷글자 | O | O | 대전 상대 |
| 3 | 몸으로 말해요 | X | O | 없음 (신체 게임이라 솔로 불가) |
| 4 | 초성 이어말하기 + 폭탄 | O | O | 사전 기반 단어 대결 상대 |
| 5 | 라이어 게임 | O | O | AI 플레이어들 (설명 한 줄씩 제시) |
| 6 | 복불복 룰렛 | - | O | 없음 (도구) |
| 7 | 사진 퀴즈 만들기 | X | O | 없음 (내 갤러리 사진으로 문제 제작) |

확장 후보(v1.1+): 속담 이어말하기, 밸런스 게임, 넌센스 퀴즈.

### 1. 연예인 퀴즈

두 가지 출제 방식을 한 게임에 통합:

- **초성 모드(기본, 오프라인 가능)**: 이름 초성(ㅇㅇㄱ) + 단계별 힌트 공개
  (직업 → 소속그룹/분야 → 대표작). 빨리 맞출수록 고득점.
- **사진 모드(온라인 전용)**: 위키피디아 REST API로 인물 사진을 **실시간 로딩**
  (앱·저장소에 사진 파일을 저장하지 않음).
  - 표시 효과는 클라이언트에서 canvas 처리: **모자이크(점점 선명해짐)** /
    **실루엣(검은 윤곽)** 중 라운드마다 선택.
  - 사진 아래에 출처·라이선스(위키미디어 커먼즈, CC 표기) 자동 표시.
  - 오프라인이거나 로딩 실패 시 해당 라운드는 초성 모드로 자동 전환.
- 데이터: `data/celebs.json` — 이름, 초성, 힌트 3단계, 위키피디아 문서 제목.
  이름·직업 등은 사실 정보라 저작권 문제 없음. 300명 이상 목표
  (가수/배우/예능인/운동선수 카테고리).

### 2. 사자성어 뒷글자

- 앞 2글자 제시 → 뒤 2글자 맞추기. 입력 방식: 4지선다(기본) / 직접 입력(고급).
- 오답·시간초과 시 뜻풀이 힌트 공개 후 재도전 1회.
- 데이터: `data/idioms.json` — 사자성어, 뜻, 난이도(초/중/고). 400개 이상 목표.
  뜻풀이는 직접 작성(사전 문장 복사 금지).

### 3. 몸으로 말해요

- 폰을 이마에 대면 제시어 표시. **아래로 기울이면 정답, 위로 기울이면 패스.**
- 라운드: 60/90/120초 선택, 카테고리 선택(동물/직업/영화드라마/동작/음식/사물).
- 종료 후 결과 화면: 맞춘 단어/패스 단어 목록.
- 데이터: `data/charades.json` — 카테고리별 제시어 100개 이상씩.

### 4. 초성 이어말하기 + 폭탄

- 초성 제시(예: ㄱㅅ) → 해당 초성 단어를 번갈아 입력. 중복·사전에 없는 단어 실패.
- **폭탄 타이머**: 총 시간은 랜덤(15~45초), 남은 시간 비공개. 폭발 순간 들고 있던
  사람 패배. 폰을 돌려가며 플레이.
- 솔로 모드: AI와 1:1 교대. AI는 사전에서 해당 초성 단어를 찾아 응수하며,
  난이도에 따라 응답 속도·포기 확률이 달라진다.
- 사전: WordChain 프로젝트의 CC0 사전(`dict_common.txt`)을 재활용해
  초성 인덱스(`data/choseong-dict.json`)로 변환 생성.

### 5. 라이어 게임

- **파티**: 인원수 설정 → 폰을 돌려 각자 단어 확인(1명만 "당신은 라이어").
  토론은 오프라인, 앱은 투표 집계와 라이어 공개만 담당.
- **솔로**: AI 플레이어 4명 등장. 제시어에 대해 각자 한 줄 설명을 내놓는데
  1명(라이어)의 설명만 미묘하게 어긋난다. 유저가 라이어를 지목.
  - 데이터: `data/liar.json` — 제시어별 정상 설명 4개 이상 + 라이어(어긋난)
    설명 2개 이상을 직접 작성. 100세트 목표.

### 6. 복불복 룰렛

- 이름(또는 벌칙)을 입력해 룰렛 항목 구성 → 돌리기 → 당첨 연출(사운드+애니메이션).
- 프리셋 벌칙 목록 내장(코 만지고 노래하기 등). 도구 성격이라 점수 없음.

### 7. 사진 퀴즈 만들기

- 내 갤러리에서 사진을 골라 문제 세트를 만들고(사진+정답 이름), 모자이크 효과로
  출제. 친구·가족 사진용. 사진은 기기 밖으로 나가지 않음(localStorage/메모리만).
- 연예인 실물 사진을 앱이 배포하지 않으므로 법적 리스크 없음(책임은 사용자 소유 사진).

## AI 봇 설계 (공통)

- **서버·API 키 없음.** 전부 내장 알고리즘.
- 난이도 3단계(쉬움/보통/어려움) — 정답률·응답 속도 파라미터로 제어.
- 퀴즈 대전(연예인·사자성어): AI가 라운드마다 확률적으로 먼저 정답을 "맞추는"
  연출(타이머 바). 유저가 먼저 답하면 승리. 난이도별 평균 응답 시간 차등.
- 초성 대결: 사전 검색 + 난이도별 응답 지연·포기 확률.
- 라이어 솔로: 데이터에 미리 작성된 설명 세트를 조합 출제.

## 법적 안전장치 정리

- 연예인 실물 사진을 앱·저장소에 **포함하지 않는다**. 위키피디아 API 실시간
  로딩 + 출처·라이선스 표기. (위키 측 사진은 대부분 위키미디어 커먼즈 자유 라이선스)
- 이름·직업·대표작 등 텍스트는 사실 정보로 저작권 대상 아님.
- 사자성어·속담은 퍼블릭 도메인. 뜻풀이는 직접 작성.
- 사전 데이터는 CC0(WordChain에서 검증 완료).
- 프로그램명("무한도전" 등)·방송사 로고·캐릭터 사용 금지. 게임 이름은 일반 명칭 사용.
- 설정 화면에 오픈소스/데이터 출처 고지 페이지 포함.

## 에러 처리

- 위키 API 실패/오프라인 → 초성 모드 자동 전환 (게임 중단 없음).
- DeviceOrientation 미지원/권한 거부 → 터치 버튼 UI로 대체.
- localStorage 없음(시크릿 모드 등) → 기록 저장만 비활성, 게임은 정상 동작.

## 테스트

- 게임 로직(점수 계산, 초성 변환, 사전 검색, AI 파라미터)은 순수 함수로 분리해
  Node 기반 단위 테스트 (`node --test`).
- 데이터 파일은 스키마 검증 스크립트로 CI에서 체크(필수 필드, 중복, 초성 일치).
- UI는 브라우저 수동 테스트 + 실기기(S20 Ultra) APK 테스트.

## 출시 체크리스트 (플레이스토어)

- targetSdk 최신, 개인정보처리방침 페이지(GitHub Pages 내), 스크린샷,
  콘텐츠 등급 설문(전체이용가 목표), 서명 키 생성·보관.

## 성공 기준 (v1.0)

1. 웹 URL 접속만으로 7개 게임 전부 플레이 가능.
2. 같은 코드의 APK가 오프라인에서 동작(사진 모드 제외).
3. 솔로 지원 게임 4종에서 AI와 대결 가능.
4. 앱에 연예인 실물 사진 파일이 하나도 포함되지 않음.
